## Functional

### Use Cases

Customer (User)
- search tomatoes (type, variante, price, geo, ...)
- add tomatoes to cart
- remove tomatoes from cart
- checkout cart (create order)
- view order
- view orders history

Provider (User)
- add tomatoes (type, variant, price, geo, ...)
- remove tomatoes
- add profile (phone, email, geo, ...)
- edit profile
